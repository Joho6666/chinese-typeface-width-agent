# 《汉字字宽调整》课程作业要求

依据用户提供的课程截图整理，原始要求如下：

1. 任意选择两个词组进行设计，名词、形容词都可以，**每组字数不少于三个字**。
2. 调整词组字宽，使每个字在视觉上保持字宽与高低一致。
3. 一组字调整为**大字面**，另一组字调整为**小字面**。
4. **只需一个页面**，放两组作品；提交 **JPG 文件和 Adobe Illustrator AI 源文件**，分成两个文件夹，以班级为单位。

## 本项目的解释与设计约定

- 第一组「科技创新」；第二组「梦想启航」，均为四个汉字。
- A4 横向画板，两组上下排列。这是项目建议，并非老师指定的画板规格。
- **共用字身基准**，比较字形实际占据面积；大字面轮廓更饱满，小字面四周留白更多。
- 90%/72% 等比例仅用于设计参考，**不是老师规定的数值**。
- “视觉宽高一致”是光学校正目标，并非强制对所有汉字做生硬的几何拉伸。
- 如果班级名称未知，使用“班级名称”占位，并在最终交付前让用户修改。
