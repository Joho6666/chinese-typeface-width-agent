# 老师布置的《汉字字宽调整》作业要求

依据课程截图整理，核心原话：

1. 任选五个？**实际要求是任意两个词组**进行设计，名词、形容词都可以，字数不少于三个字；
2. 调整词组字宽，使每个字在视觉上保持字宽高低一致；
3. 一组字调整为大字面，一组字调低小字面；
4. 只需一个页面，放两组作品；提交 JPG 文件和 AI 源文件，分成两个文件夹，以班级为单位。

## 本项目的约定与解释

- 第一组「科技创新」；第二组「梦想启航」。均为四个汉字。
- A4 横向画板，两组上下排列。这个画板规格是项目建议，并非截图明确要求。
- **统一字身基准，比较实际字形的可见面积**；大字面轮廓更饱满，小字面轮廓留白更明显。
- 字数、分组、文件要求是老师硬约束；90%/72% 等比例是项目的设计参考，不能误称为老师要求。
- “视觉上宽高一致”不等于每个字应机械拉伸到完全同等宽高；应结合字形复杂度、重心等进行光学校正。
- JPG 和 AI 必须分别放在两个文件夹。若班级名称未知，由 Agent 询问用户或采用占位文件夹名（并说明）。
